# Star — инструкция по запуску

Star — это крутящаяся ASCII-звезда прямо в терминале. Её можно раскрасить, поменять символы, из которых она сделана, и направление вращения. Ещё в комплекте есть установщик, который добавит команду `star`, чтобы запускать её откуда угодно.

Исходники на GitHub: https://github.com/Ghoex/david-star

## Что понадобится

- Linux и Python 3.6 или новее
- Терминал с поддержкой 256 цветов (в большинстве современных он есть)

## Шаг 1. Скачиваем проект

Открой терминал и выполни:

```bash
git clone https://github.com/Ghoex/david-star.git
cd david-star
```

Если `git` не установлен, его можно поставить командой `sudo apt install git`. Или просто скачай ZIP-архив с GitHub и распакуй в любое место.

Структура папок такая:

```
david-star/
├── main.py      # сама анимация
└── init/
    └── init.py  # установщик команды star
```

Важно: `main.py` должен лежать на один уровень выше папки `init`. Иначе установщик его не найдёт.

## Шаг 2. Устанавливаем команду star

```bash
cd david-star/init
python3 init.py
```

Команда `star` появится в папке `~/.local/bin`.

Если установщик написал, что эта папка не в `PATH`, сделай один раз:

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
```

Если используешь zsh, вместо `~/.bashrc` пиши `~/.zshrc`. После этого закрой терминал и открой новый (или перезагрузи компьютер), иначе команда не заработает.

## Шаг 3. Запускаем

```bash
star
```

Звезда начнёт вращаться слева направо, цвет по умолчанию — голубой. Чтобы остановить, нажми `Ctrl+C`.

## Настройки

Можно менять вид звезды, добавляя опции:

```bash
star -c magenta               # другой цвет
star -s '#*+'                 # звезда из других символов
star -d up                    # вращение снизу вверх
star -c green -s '@' -d all   # всё сразу
```

| Опция | Что делает | Значения |
| --- | --- | --- |
| `-c`, `--color` | Цвет | `cyan` (по умолчанию), `blue`, `green`, `red`, `magenta`, `yellow`, `white` или свои коды из 256-цветной палитры, например `27,51,231` (от задней части к передней) |
| `-s`, `--chars` | Символы, которыми рисуется звезда | Любые символы, например `'#*+'`. По умолчанию — исходный арт |
| `-d`, `--direction` | Направление вращения | `right` (по умолчанию), `left`, `up`, `down`, `all` |

Чтобы посмотреть все опции прямо в терминале, введи `star -h`.

## Запуск без установки

Если не хочешь ставить команду, можно запускать программу прямо из папки проекта:

```bash
cd david-star
python3 main.py -c blue -d down
```

## Удаление

```bash
cd david-star/init
python3 init.py --uninstall
```

Удаляется только файл `star`, который создал установщик. Остальное не трогается.

## Дополнительные опции установщика

| Опция | Что делает |
| --- | --- |
| `--name NAME` | Установить команду под другим именем (по умолчанию `star`) |
| `--dir PATH` | Положить команду в другую папку (по умолчанию `~/.local/bin`) |
| `--force` | Перезаписать существующий файл, который установщик не создавал |
| `--uninstall` | Удалить команду |

Например, `python3 init.py --name spin` создаст команду `spin`.

## Если что-то не работает

- **`star: команда не найдена`.** Папка `~/.local/bin` не добавлена в `PATH`. Выполни команду из шага 2, открой новый терминал или перезагрузи компьютер. Можно также запустить `~/.local/bin/star` полным путём.
- **`main.py not found`.** `main.py` лежит не на уровень выше `init`. Перенеси его и запусти установщик заново.
- **Цвета тусклые.** Попробуй `-c white` или терминал с поддержкой 256 цветов.
- **Переместил папку.** Запусти `python3 init.py` заново из новой папки, чтобы команда указывала на правильный путь.
